# 实验 7：iPhone 扫描驱动的 OpenPlan3D 体素编辑器

这是独立实验。主入口是 OpenPlan3D 隔离副本的原版编辑器，保留其平面图、3D 工具栏、属性栏与原有家具放置流程；`/voxel` 是早期独立原型，不再作为扫描编辑主入口。`reference/openPlan3D` 和 `reference/3d-model-anything` 仅供参考，不修改；不改 iPhone 采集端。

## 启动与打开

需要 Node.js 24 和 npm。在本目录运行：

```sh
cd openplan
npm ci
npm run dev -- --host 127.0.0.1 --port 5191
```

用 Edge 打开 <http://127.0.0.1:5191/editor?scan=office-2>。无参数的 `/editor` 默认打开第二次扫描；首页也提供两次扫描入口。`office-1` 可在 `?scan=office-1` 打开。扫描仍留在 `experiment/.private/`，网页仅通过限制为本机访问的只读接口加载。每次扫描是独立项目，自动保存的编辑不会相互覆盖。

## 数据和图层

- 原始 RoomPlan 生成可编辑的 OpenPlan3D 墙、窗与家具代理。扫描项目保留原始会话的 X/Z 坐标，以便将实验 4 的房间局部体素通过该次 `worldToRoom` 逆变换准确叠加。旧版自动正交导入的本地项目保留，新配准项目使用 `registered-v2` ID。
- 实验 4 的 `mesh-surface-grids.json` 已缓存 TSDF 融合网格与体素盒的表面相交结果。第二次扫描 20 cm 为 1,458 个真实表面格，第一次为 1,750 个；这些格是扫描表面证据，不是实心房间或已证实的物体内部。
- 平整层独立从 RoomPlan 地面轮廓、墙与语义物体包围框生成。墙和地面吸附到同一米制网格，缺失的闭合墙段单独标为推断。测量层仍可对照，不会因平整化被覆盖。
- 物体分组先用 RoomPlan 朝向包围框关联扫描表面格，再保留未分类证据。它是有语义的边界候选，不等于已经得到逐点精确实例分割。
- 可用的原始参考资料是全帧深度归并点、TSDF 网格和第二次扫描的原包 LiDAR 网格。当前数据包没有真实 Gaussian splat 资产；普通 PLY、TSDF 或点云不能标作高斯泼溅。

## 在原版 3D 画布中操作

默认看到第二次扫描的 20 cm 实测表面方块。左侧扫描面板可以切换「实测表面方块 / 平整语义草模 / 两者」、TSDF 与第二次扫描的 LiDAR 来源、20/10/5/2.5 cm 格长，以及 TSDF 网格原貌、LiDAR 网格原貌、全帧深度点。2.5 cm 档保留完整格数统计，但为交互速度抽样绘制，面板分别报告两者。可以按 RoomPlan 物体框隔离关联格，或重新显示原版建筑模型。

在同一画布输入名称、语义、X×Y×Z 格数和格长，点击「放置」后在扫描格或地面上点击即可新建体素盒；可选中后移动、旋转、改名或删除。新盒按扫描分别保存在本浏览器，并可导入/导出体素 JSON。**OpenPlan3D 顶栏的项目保存和导出尚不包含这些体素盒**；要备份体素编辑，请使用左侧的「导出体素 JSON」。当前是点击放置固定尺寸，尚未实现鼠标框选底面再拉伸。

## 本轮验证

Edge 中两次扫描分别显示 1,458 / 1,750 个 20 cm TSDF 表面格；第二次扫描的平整草模为 1,338 格。三种原始参考层均可切换，创建的 2×3×1 体素盒在刷新后保留，移动和改名生效，两次扫描互不串场。`npm run check`、`npm run build`、体素分类与配准测试通过。

## 范围

当前完成的是在原版 3D 场景中看见并编辑扫描相关体素的第一步。对象精确边界纠错、墙面框选、跨平面拉伸、统一的 2D/3D/体素撤销历史、AI 局部建模与真实 splat 导入仍是后续任务，不应以格子密度切换代替建模。任务顺序与验收标准见 [自动化路线](../../automation/voxel-editor/WEB_VOXEL_INTEGRATION_PLAN.md)，状态以 `automation/voxel-editor/STATE.json` 为准。
