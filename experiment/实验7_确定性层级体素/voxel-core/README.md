# 局部体素数据原型

`index.ts` 提供独立于渲染和家具的对象局部占据：每个叶格以 `(level,x,y,z)` 存储，`baseStep / 2^level` 是格长。`origin` 是局部格原点的世界位置，`quarterTurns` 是绕原点的 Y 轴 90°旋转。每个对象有独立 ID、语义、来源与锁定状态。不存在的格是空；本原型尚未区分扫描未知区域。

`VoxelDocument` 支持创建整数尺寸块、加删格、局部拆格、全局拆到指定层级、整件移动/旋转、点查询、撤销/重做和 JSON 往返。`snapshot()` 与 `getObject()` 返回副本；修改必须通过命令。单条命令先验证再整体提交，失败不改变文档；新编辑清除 redo。保存前可使用 `toJSON()`，读取使用 `fromJSON()`，它会拒绝非法和重叠父子格。

运行：`node --test voxel-core/index.test.mjs`（从实验 7 根目录执行，需要支持 TypeScript 类型擦除的 Node 版本，例如 Node 24）。

这是可接线的正确性原型，不是完整架构：历史使用全量快照，查询线性扫描，单对象最多 100,000 格；没有 chunk、空间索引、平面裁剪、扫描 unknown/conflict、承载关系、实例拆合、plan/voxel 统一事务或浏览器持久化故障恢复。`shapeHash` 是非加密的稳定指纹，不可用作安全或持久化完整性校验。锚定对象和父件移动的策略须在上层实现，不要宣称这些能力已经完成。
