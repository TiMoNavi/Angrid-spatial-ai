## 完成定义和回档

每个 E8/E9/E10 实验各做独立 commit，不能把阶段验收都写进一个尚未验证的大提交。每阶段提交后在 STATE.json 填 commit、测试命令、Edge 结果与未完成限制；失败则保持 in_progress，绝不标 done。复现时先记录 git status，再从对应 commit 的实验目录重跑，私有数据只按本机输入路径读取。三阶段完成前不把 E10 标为 merged；推送前做 staged path/大文件/密钥/隐私检查与 git diff --check，远端 push 完成后记录分支和远端 commit，不强推。
