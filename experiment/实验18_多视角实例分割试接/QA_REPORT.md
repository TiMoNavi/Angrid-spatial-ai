## 椅子提示修正循环

原 0173 提示 bbox 为 `[0.196, 0, 1, 0.744]`，下半部椅座、轮脚在框外；部分正点落在椅背网孔或右后方背景上。原掩码覆盖窗帘、桌底和穿过椅背可见的背景，却漏掉多数黑色椅框。

AI 看图后另存 `agent_review_correction`，框改为 `[0.23, 0.19, 0.999, 0.999]`，正点放在头枕外框、背部支架、座垫和扶手，负点放在右侧桌面、窗帘和左侧地面。只复跑这一张照片，原提示文件未改。

- 修正后掩码为 215,117 pixels，占图 31.1223%；原掩码为 157,117 pixels，占图 22.7310%。数量增大不代表单独的质量指标。
- 视觉核对可见：主要椅框、头枕、座垫及扶手获得覆盖，大量窗帘和桌面背景被排除；桌底右侧仍有碎边，轮脚仍不完整。这一轮有改善，尚不能当作完整实例。
- 修正后 score 0.969946，只是模型掩码评分；类别仍未确认。
- 旧 adapter 只能删面，不能补回被旧 bbox 或类别先验排除的面；当前脚本明确拒绝这种误用。另用全原面重投影：原椅子掩码得到 3,003 面，修正掩码得到 2,004 面；两者共同 820 面，修正后有 1,184 个新面。修正结果中 1,693 面在旧 E15 候选之外、532 面与旧 owner 相交，保护面泄漏为 0。这是边界显著改变，不是质量或准确率的证明。

## 性能和局限

六个原提示、四张照片，在 Intel CPU 上本次模型每张编码约 1.46–2.34 秒，每次提示解码约 0.097–0.439 秒，相邻同照片提示复用编码；完整六提示进程约 15.4 秒，含加载。椅子修正单张编码 1.709 秒、解码 0.206 秒。`mask_trial.py` 的 `maskRuntimeSeconds` 是 PNG 读取/筛选准备耗时，不能写成模型推理速度。

扫描中的蓝色座椅原面共享边连通分量为 3,044 / 1,746 / 5 面，两大块空间相邻却不共享顶点，可能是扫描裂缝；因此“只保留一个连通块”会切掉同一件物体。距离近也不能直接合并，因为椅子、桌子和杂物会接触。

全原面重投影已做试验，但原提示椅子 3,003 面中有 1,911 面不属于旧流程使用的 ARKit 家具候选类别（0/4/5），其中 class 6 有 1,699 面，存在明显背景吸附风险。修正后仅 12/2,004 面不属于该先验，支持“大片背景减少”的视觉观察，但 ARKit 类别并非真值，不能据此宣布边界准确。修正后仍有 532 面与旧 owner 相交，须逐面审核。深度约束沿用 E15 容差，不是精确遮挡光线追踪。后续需验证多视角实例关联、更可靠的深度遮挡、距离/法线/曲率约束图切分、类别冲突和旧 owner 冲突。补腿/柜门等不可见几何应保留为独立重建假设，不能伪装为扫描观察面。本实验没有完成实例合并，也未自动更改已确认体素。
