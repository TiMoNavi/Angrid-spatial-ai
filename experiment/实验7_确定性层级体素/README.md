# 实验 7：空间体素工作台

这是一个独立实验：以 OpenPlan3D 的隔离副本作为网页编辑器基线，另外提供可操作真实格子的体素原型。`reference/openPlan3D` 和 `reference/3d-model-anything` 是只读参考，不需要修改 iPhone 采集端。

## 启动

需要 Node.js 24 和 npm。在本目录执行：

```sh
cd openplan
npm ci
npm run dev -- --host 127.0.0.1 --port 5191
```

用 Edge 打开 <http://127.0.0.1:5191/voxel>；如果端口被占用，以终端实际显示的地址为准。平面图编辑器在 `/editor`，与体素页面目前是两个独立工作区。

## 当前可以尝试

选择「框选创建」，在地面或已有体素顶面拖出矩形底面，输入格子边长、高度格数、名称和语义后确认。切换「选择」点击格子，可细分为八格或删除；也可以选中物体改名、输入坐标移动、绕 Y 轴旋转 90° 或删除。撤销和重做针对当前体素会话；浏览器本地保存/读取以及 JSON 导入/导出用于体素场景。

格子由对象局部占据数据表示，不同对象保留独立身份。细分保留原位置和体积，能够继续选择和删除子格。当前高度由输入框确定，尚无鼠标向上拉伸手柄；创建只支持水平面，尚无墙面框选。

## 验证与限制

- Edge 实际鼠标验证过框选创建、撤销/重做及保存后重新载入；`npm run check` 无错误和警告，生产构建通过。
- 从本目录运行 `node --test voxel-core/index.test.mjs` 可检查局部细分、孔洞、对象身份、保存和撤销等核心行为。
- `/voxel` 和 `/editor` 尚未共享场景、选中状态、历史或保存；扫描离线导入、物体边界识别、平面图转体素和 AI 布局/细化尚未接入。此原型不能代表这些功能已完成。
- 网格历史目前使用全场景快照，查询为线性扫描，每个物体限制 100,000 格；大场景需要增量历史、空间索引和性能验证。
- OpenPlan3D 副本缺少上游模型和材质等资产，依赖相关资产或云服务的功能可能不可用。来源和隔离情况见 [openplan/README_EXPERIMENT7.md](openplan/README_EXPERIMENT7.md)。

后续阶段和验收标准见 [自动化路线](../../automation/voxel-editor/WEB_VOXEL_INTEGRATION_PLAN.md)；任务状态以 `automation/voxel-editor/STATE.json` 为准。
