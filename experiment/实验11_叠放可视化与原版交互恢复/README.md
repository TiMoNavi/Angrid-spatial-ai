## 原则

- 同一米制坐标中，原始 LiDAR/深度/TSDF 是证据，结构与家具候选是分类结果，用户盒才是可编辑的实心设计体素。unknown 不代表净空。
- 墙与地板维持平整的 1–2 格薄壳；家具先按物体切分，再处理候选表面；杂物独立且可关闭。表面体素不等于实心家具。
- 图层透明度、剖切和热力图只改变查看方式，不改变原始数据。无真实 Gaussian splat 资产时不显示伪造数据。
- ThreeUI 源码如需下载，先验证条款；受限完整快照留在不提交 Git 的私有目录。

## 启动

在 openplan 目录运行 npm ci --prefer-offline --no-audit --no-fund，然后 npm run dev -- --host 127.0.0.1 --port 5193 --strictPort；使用 Microsoft Edge 打开 http://127.0.0.1:5193/editor?scan=office-2 。

## 编辑和观察

1. 顶栏 2D/3D 仍是原版往返入口。左侧 Build 及右侧 Layers 面板在 3D 模式保留；平面绘制工具会切回 2D，原版家具目录可以在 3D 启动家具放置。
   3D 视角可自由旋转并停留在用户选择的位置；Cathode Studio 的鼠标自动回正没有带入编辑器。
2. 默认编辑预设只显示平整结构、家具分类表面和几何修正。用户设计格为有体积的实体盒，默认不透明，独立于测量证据；点击已放盒的顶部可继续叠放。
3. 逐层开关控制 LiDAR、深度、TSDF、表面格、结构、家具、杂物候选等证据。可以单独调各层不透明度与剖切，用户盒另有透明度、逐格边线和颜色控制。
   有用户体素盒时，“设计优先”把已打开扫描证据的有效不透明度压至不超过 18%，保留滑块原值；切回“扫描对照”恢复原透明度。用户实体默认不参加扫描剖切，可独立开启。
4. 高度热力图仅取用户体素格中心离地高度，米制色标由当前设计计算。它不表示点云密度、扫描置信度或空余空间。
5. 图层优先级只描述视觉绘制级别；真实三维前后仍受深度测试影响。高密度证据默认关闭或低不透明度，不写入遮挡深度；选中盒轮廓可穿透提示。尚无真实 Gaussian splat 输入，开关禁用。
6. Studio 采用黑灰渐变背景、静态轻颗粒、半透明信息层和恒宽灰白格边。半透明盒仍能看清格边；关闭用户盒或把不透明度设为 0 会同时隐藏实体、格边和选中轮廓。

完整工程导出包含原生平面、体素盒颜色和扫描来源引用；扫描资产仍在本机。实验 11 使用独立项目数据库、项目 ID 和用户设计键，不覆盖实验 10。旧项目的缺省颜色可以导入并以默认色展示。
